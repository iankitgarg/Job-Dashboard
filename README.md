# Job-Dashboard
Archiving Job Scheduler

Steps to run Application :
1. Clone this repo in IDE enabled with already SAP FIORI Development (VS Code, Business Application Studio etc.)
2. In Terminal, open root folder directory of cloned project.
3. Run -- cd jobdashboard
4. Run -- npm install
5. Run -- npm Start (Application will run in new browser tab)
